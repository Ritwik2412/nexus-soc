Communication pattern
Agents operate sequentially in a directed pipeline. Each agent receives the prior agent's structured output as its input context — a chain-of-thought relay architecture. All inter-agent messages pass through a shared context object managed by the FastAPI backend. No shared mutable state between agents.
Security guardrails
🔒
Prompt injection defense
Security agent classifies all inputs before they reach any LLM. Jailbreaks and injections are rejected at the gate.
🎭
Role constraint enforcement
Each agent has a scoped system prompt. No agent can invoke another — all routing flows through the backend orchestrator.
📵
Output filtering
Critic agent checks for hallucinations, PII leakage, and ungrounded claims before report generation proceeds.
📋
Full audit trail
Every agent invocation is logged with its input, output, and decision rationale. Visible in Pipeline Trace tab.
