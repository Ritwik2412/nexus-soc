↩ Retry Loop: If Review Agent rejects the remediation plan, it sends specific revision instructions back to the Remediation Agent. This repeats up to 2 times before the Reporter proceeds with the best available plan. This is genuine agent negotiation.
Communication Pattern
Agents operate in a sequential + cyclical hybrid pipeline. The Remediation ↔ Review loop implements genuine agent negotiation — the Review Agent can reject and provide structured feedback, forcing the Remediation Agent to revise. All inter-agent messages are structured JSON passed through the FastAPI orchestration layer.
Security Guardrails
🔒
Prompt Injection Defense
Guard Agent classifies every input before it enters the pipeline. Jailbreaks and injections are blocked at the gate.
🎭
Role Constraint Enforcement
Each agent has a scoped system prompt defining strict boundaries. No agent can invoke another directly.
🔁
Retry & Failure Handling
Review Agent can reject inadequate plans up to 2 times. All retries are logged and visible in the Agent Trace.
📋
Full Audit Trail
Every agent invocation — including retries — is logged with raw input/output. Visible in the Agent Trace tab.
